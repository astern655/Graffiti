# Graffiti — 화재 위험도 콘솔

2D 물류창고 CAD 도면에 건축 자재를 지정하면, **모든 지점 발화를 시뮬레이션해 공간 화재 위험도**를 계산·시각화하는 설계 단계 분석 도구. 빌드·서버·의존성 없는 **단일 정적 사이트**(순수 JS + Canvas).

## 실행
`index.html`을 브라우저로 열면 됩니다(더블클릭 / `file://`). 정적 서버로도 가능:
```
python -m http.server 8080   # → http://localhost:8080
```

## 기능
- **위험도 지도** — 자재 발화성·연소·유독가스를 격자 다익스트라 확산 + 거리 감쇠로 합산한 공간 위험 히트맵. 레이어: 통합 / 화염 / 유독가스 / 경도(소방 진입 난이도).
- **발화점 시나리오** — 좌클릭 발화점 지정 → 확산 시뮬 + 가장 안전한 지점, 우클릭 목표 핑 → 최소 노출 안전 진입 경로.
- **발화 가중치** — 우클릭으로 지점별 내용물 위험 5단계 가중, 좌클릭 자재 편집. 위험도 지도 전 기능 + 가중치.
- 구획(구조·바닥)·벽(방화벽 포함, 외벽 프레임)에 자재 지정, 자재 번호 매핑.

## 구성
- `index.html` — UI/레이아웃
- `data.js` — 자재 상수·지오메트리·시나리오·상수(RISK 튜닝)
- `risk.js` — 공간 위험도 엔진(격자·다익스트라·2채널 확산·안전경로)
- `ui.js` — 캔버스 렌더·인터랙션
- `selftest.js` — `node selftest.js` 로직 검증

## 배포 (Vercel)
정적 사이트이므로 무설정 배포됩니다. Vercel에서 이 저장소를 Import → Framework Preset "Other" → 그대로 Deploy.

> 위험 상수(발화성·확산·유독가스·경도)는 NFPA t²·화재 문헌을 참고한 **상대 비교용 추정값**이며, CFAST 등 실측 보정은 향후 과제입니다.
